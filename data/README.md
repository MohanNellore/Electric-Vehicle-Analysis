# Data

The dataset is too large to keep in this repository, so download it and place it in this folder.

**File name expected by the notebook:** `Electric_Vehicle_Population_Data1.csv`

**Option 1: Google Drive copy used in this project**
https://drive.google.com/file/d/1RPpjwt6lRFtIlHPE15wx3bmDTtv2rweB/view?usp=drive_link

**Option 2: Official source (always the latest version)**
Electric Vehicle Population Data, Washington State Department of Licensing (DOL), on data.wa.gov:
https://data.wa.gov/d/f6w7-q2d2
Use *Export* and choose CSV. The numbers in this project come from the copy in Option 1, so the latest export may differ slightly.

After downloading you should have:

```
data/
└── Electric_Vehicle_Population_Data1.csv
```

CSV files in this folder are ignored by Git (see `.gitignore`), so the large file is never committed by accident.
